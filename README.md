# Registro Viaggi ✈️

Progetto scolastico realizzato con:

- HTML
- CSS
- Bootstrap
- JavaScript
- Gemini API
- GitHub

## Funzioni del sito

- Aggiunta viaggi
- Eliminazione singolo viaggio
- Eliminazione totale viaggi
- Calcolo totale speso
- Numero voli effettuati
- Salvataggio Local Storage
- Suggerimenti AI con Gemini
